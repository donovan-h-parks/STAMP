# STAMP v2 (Python)

The original Python 2 / PyQt4 implementation of STAMP, kept as the reference
for the Rust port. It is no longer developed here and will be removed once the
port reaches parity.

`golden/` holds a Python 2.7 environment definition and scripts that run the
original statistics headlessly to produce the reference outputs in
`tests/golden`. See `tests/golden/README.md`.
